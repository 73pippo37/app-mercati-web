# Mercati

Web app per iPhone (si installa da Safari → Condividi → Aggiungi a schermata Home).
I dati arrivano dal bot Telegram su Supabase; l'accesso richiede il codice personale che il bot dà con /app.

Grafici: [TradingView Lightweight Charts](https://www.tradingview.com/lightweight-charts/) (Apache 2.0).
